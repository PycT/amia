# Planning & Management Templates

This file provides standardized frameworks for recurring planning sessions, problem teardowns, and strategy reviews.

---

## 1. Project Initialization Template

```markdown
# [Project Name]

## Overview
- **Project Name**: [Name]
- **Start Date**: [YYYY-MM-DD]
- **Status**: Active / On Hold / Completed / Archived
- **Objective**: [Brief project description and primary objective]

## Current Sprint
- **Sprint**: [Sprint identifier]
- **Sprint Goal**: [Primary objective for current sprint]

## Key Contacts
See [contacts.md](contacts.md) for the full contacts directory.

## Navigation
- [contacts.md](contacts.md) -- Stakeholder and contact tracking.
- [references/](references/) -- Reference materials and background assets.
```

## 3. Product Idea & Problem Teardown

```markdown
# Product Idea Teardown: [Idea Name]

## 1. Target Pain Point
- **Category**: Time / Money / Compliance & Security
- **Problem Statement**: What exact breakdown or inefficiency exists?

## 2. Market & Revenue Potential
- **Target Audience**: Who is the buyer? (e.g., VP of Data, CTO, Compliance Officer)
- **Willingness to Pay**: Estimated contract value and target revenue contribution.

## 3. Content & Teardown Angle
- **Public Teardown Concept**: What honest public analysis or breakdown can be published around this problem?
- **Key Takeaways for Readers**:

## 4. Minimum Viable Service / Validation Plan
- **Pre-Revenue Validation**: How to validate before invoicing.
- **Revenue Milestones**:
```
